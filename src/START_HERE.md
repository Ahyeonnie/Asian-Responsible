**"Dashboard won't open?"**  
→ Click rapidly (within 2 seconds)  
→ After 5 clicks, press Ctrl+Shift+D

**"Changes don't show on website?"**  
→ Refresh the page (F5)  
→ localStorage updates require refresh

**"How many items can I add?"**  
→ localStorage: ~100-500 items (browser limit)  
→ MongoDB: Unlimited

**"When should I use MongoDB?"**  
→ Need cloud backups  
→ Need multi-user access  
→ Need more than 100 items  
→ Need API access
